# Amazfit Workout Bridge 🏃⌚

אפליקציית PWA לשיתוף אימונים ישירות מוואטסאפ (צילום מסך או טקסט) לשעוני Amazfit Balance / Balance 2.

## איך זה עובד?
1. המאמן שולח צילום מסך של אימון (מ-Garmin Connect / וואטסאפ).
2. לוחצים על התמונה ➔ **שתף (Share)** ➔ בוחרים ב-**Workout Bridge**.
3. האפליקציה נפתחת, מפענחת את האימון (חימום, חזרות, זמני ריצה והתאוששות).
4. לוחצים על **"🚀 שלח לשעון"** ➔ האימון נשלח לחשבון Intervals.icu ונוחת ישירות בשעון בתוך אפליקציית הריצה המקורית!

## העלאה ל-Vercel
הרץ בטרמינל בתיקייה זו:
```bash
npx vercel
```
(או הרץ את `deploy.ps1`).

לאחר שתקבל את הכתובת של Vercel (לדוגמה `https://your-app.vercel.app`):
1. פתח את הכתובת בכרום בטלפון הנייד.
2. לחץ על כפתור **"התקן"** (או בתפריט שלוש הנקודות ➔ "הוסף למסך הבית").
3. מעכשיו, האפליקציה מופיעה בתפריט ה"שתף" של אנדרואיד מכל מקום!
